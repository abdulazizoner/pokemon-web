# Paralel Arşiv / Card Showcase

Natro paylaşımlı hosting üzerinde yayınlanmak üzere hazırlanan, Shopier ürün sayfalarına yönlendiren statik koleksiyon kartı vitrini.

## Kapsam

- Astro + TypeScript
- Tamamen statik çıktı
- Yerel içerik dosyaları ve görseller
- Arama, filtreleme, ürün detayları
- Shopier dış satış bağlantıları
- Backend, veritabanı, üyelik, sepet ve ödeme yok

## Yerel çalışma

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
pnpm test:e2e
```

`pnpm build` sonrasında Natro'ya yüklenecek dosyalar `dist/` içinde oluşur.

## Geçici içerikler

`Paralel Arşiv` adı, iletişim bilgileri, kart kayıtları ve görseller geçicidir. WP-01, WP-02 ve WP-03 tamamlandığında gerçek bilgilerle değiştirilecektir.

Detaylar için `docs/` klasörüne bakın.
